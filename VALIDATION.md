# RAMAK redesign validation

Validated locally against the production build on 12 September 2026. No website deployment was performed.

## Checks passed

- `npm ci` using the existing package lock (no application dependency changes).
- `npm run lint`.
- `npm run typecheck` (existing JavaScript configuration; `checkJs` remains false).
- `npm run verify:content`: noindex/nofollow, robots blocking, static form, central demo fields.
- `npm run build`.
- English and Arabic at 320, 375, 430, 768, 1024, 1280, 1440 and 1920px.
- All image references loaded; no horizontal overflow or runtime/console errors.
- 80% content width at tested tablet/desktop sizes; adaptive mobile gutters.
- Mobile menu navigation, focus capture, Escape dismissal and trigger-focus restoration.
- Service dialogs, keyboard focus cycling and dismissal; FAQ expansion.
- Language persistence after reload; internal navigation targets.
- Empty form validation and first-error focus; email required when email contact is selected.
- Successful demo-form completion sends zero network requests and does not persist enquiry data.
- Data remains until confirmation closes, duplicate submission is disabled, then the form resets.
- Placeholder telephone, email and WhatsApp actions do not launch real communication apps.
- Reduced-motion styles and demo-indexing safeguards.
- No serious or critical axe violations on English/Arabic desktop/mobile pages or the form confirmation.

## Lighthouse

One local mobile-emulation run using Lighthouse 13 and Chromium 153:

| Category | Score |
|---|---:|
| Performance | 91 |
| Accessibility | 100 |
| Best Practices | 100 |
| SEO | 69 |

SEO is intentionally restricted by the demonstration's noindex/nofollow and robots safeguards. It is not a production SEO pass. Scores vary with browser, hardware, load and network conditions. The automated checks are not a formal accessibility certification or a claim that every possible device has been tested.

The normal Playwright browser download was unavailable in this execution environment. A compatible packaged Chromium 153 executable was used through the test script's `CHROME_PATH` option instead; no special browser dependency was added to the application. On a normal workstation, `npx playwright install chromium` followed by `npm run test:browser` is sufficient.

Screenshots generated by the test are stored under ignored `test-results/`. Image-generation prompts, disclosure, and asset locations are in `AI_IMAGE_PROMPTS.md`. Client business details still require approval before public launch.
